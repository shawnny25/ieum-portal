개시 전 점검 항목

테스트 기간에는 계정 비밀번호를 간단한 임시값으로 두고 테스트 데이터를 넣어 두었습니다. 아래 항목을 모두 처리한 뒤 수행기관에 계정을 배포합니다. 처리한 항목은 칸에 체크하고 날짜를 적습니다.

1. 계정 · 비밀번호

  • 관리자 계정 비밀번호를 다른 사이트에서 쓰지 않는 긴 비밀번호로 변경 (전체 관리자)
  • 전문가 계정 비밀번호 변경 또는 실제 전문가에게 임시 비밀번호 전달 후 변경 안내
  • 테스트 기관 계정 삭제: sionlee0825@gmail.com(함께하는세상), citysion1@gmail.com(따듯한마음)
  • 실제 수행기관 등록 후 기관별 계정 발급, 이메일과 임시 비밀번호 전달 (초대 메일은 자동 발송되지 않음)
  • 최종 관리자 명단 확정 — 불필요한 관리자 계정은 만들지 않기
  • (선택) 관리자 MFA — 보류 중, 필요하면 반나절 작업

2. 테스트 데이터 정리

기관을 삭제하면 그 기관의 제출·예산·컨설팅 일정·계정이 함께 삭제됩니다 (계정 관리 → 기관 삭제, 관리자 비밀번호 필요).

  • 테스트 기관 삭제: 따듯한마음, 함께하는세상
  • 테스트 컨설팅 회차 · 후보 일시 · 전문가 가능 일시 정리 (사업 설정 → 컨설팅 회차)
  • 사업 설정 값 확정: 사업명, 연도, 보고서 마감일, 공지사항, 연간 일정
  • 테스트 파일 삭제: Cloudflare R2 ieum-files 와 백업 버킷 ieum-files-backup 의 org-22/ 폴더 (백업 사본은 자동으로 지워지지 않음)
  • 활동 로그는 변경·삭제 불가 설계 — 테스트 기록을 남길지, 개시 전 SQL 로 비울지 결정

3. 메일 발송

현재 자동 메일은 개인 Gmail(sionlee0825@gmail.com)에서 발송됩니다. 개시 전 회사 메일로 바꿉니다.

  • 경영팀에 메일플러그 SMTP 허용 요청 (「메일플러그 SMTP 연동 요청」 문서 전달)
  • 로컬에서 테스트 메일 발송 후 보낸메일함 저장 여부 확인
  • Vercel 발송 설정(SMTP_HOST · SMTP_USER · SMTP_PASS · MAIL_FROM) 교체 후 재배포
  • Supabase 인증 메일(비밀번호 재설정) SMTP 설정 교체
  • 보낸메일함에 남지 않으면 관리자 주소 숨은참조(BCC) 추가
  • 실제 기관 담당자 주소로 컨설팅 안내 메일 발송 시험 (스팸함 여부 포함)

4. 인프라 · 비용

  • 요금제 결재: Vercel Pro · Supabase Pro 전환(사업비, 월 $45 · 연 약 76만원), Claude Code Max 5x 구독(관리운영비, 월 $100 · 연 약 168만원) — 근거는 기획서 8.4 ~ 8.6
  • Vercel Pro(월 $20) 전환 — Hobby 플랜은 개인·비상업 용도라 기관 공식 업무엔 Pro 가 맞음. 팀(기관) 계정으로 운영
  • Supabase Pro(월 $25) 전환 — 자동 일시정지 해제, 공식 일일 백업(7일) 추가. 전환 후 Database → Backups 에 백업이 쌓이는지 확인
  • Claude Code Max 5x(월 $100) 구독 — 개발 · 유지보수 담당자 계정
  • 사용 안 하는 Supabase 프로젝트 gongmo-2027(비활성) 정리
  • 사용 안 하는 Vercel 도메인 gpportal.vercel.app 정리
  • Sentry 무료 체험(14일) 종료 후에도 오류 수집이 계속되는지 확인 (무료 월 5,000건)
  • 접속 주소 결정: 기본 ieum-portal.vercel.app 유지 또는 회사 도메인 연결

5. 개시 직전 · 직후 확인

  • 매일 백업 정상 동작: Supabase Storage backups 에 날짜별 JSON, R2 ieum-files-backup 에 파일 사본 (매일 한국 시간 오전 9시)
  • 권한 검증 스크립트 27항목 통과: node --env-file=.env.local scripts/e2e-check.mjs
  • 기관 · 전문가 · 관리자 계정으로 각각 로그인해 주요 화면 확인 (PC · 휴대폰)
  • 파일 업로드 · 다운로드 확인 (파일당 200MB 이하)
  • Sentry 알림 메일 수신 주소 확인, 테스트 오류 Resolve 처리
  • 개시 후 1주일간 Sentry 오류 · 문의 집중 확인
