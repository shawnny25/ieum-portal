1. 시작하기

1.1 접속과 로그인

  1. 브라우저(Chrome, Edge 권장)에서 https://ieum-portal.vercel.app 에 접속합니다. 휴대폰·태블릿 브라우저에서도 쓸 수 있습니다.
  2. 로그인 화면 위쪽에 KCOC · 사랑의열매 로고가 보이면 올바른 주소입니다.
  3. 이메일과 비밀번호를 입력하고 [로그인]을 누릅니다.
  4. 로그인하면 관리자 메뉴 11개가 표시되고, 첫 화면으로 통합 대시보드가 열립니다.

이메일이나 비밀번호가 틀리면 “이메일 또는 비밀번호가 올바르지 않습니다.”라는 안내가 나옵니다.

비밀번호를 잊었거나 바꾸고 싶을 때

  1. 로그인 화면에서 이메일 칸에 본인 이메일을 먼저 입력합니다.
  2. 아래쪽 비밀번호 재설정 링크를 누릅니다. “비밀번호 재설정 메일을 보냈습니다.”가 표시됩니다.
  3. 받은 메일의 링크를 열면 “새 비밀번호를 설정해 주세요” 화면이 나옵니다. 새 비밀번호(8자 이상)를 두 번 입력하고 [설정하고 시작하기]를 누릅니다.
아이디(이메일)는 바뀌지 않습니다. 링크가 “만료되었거나 이미 사용되었습니다”라고 나오면 재설정을 다시 요청하세요. 메일이 계속 오지 않으면 시스템 담당자에게 재발송을 요청합니다.

1.2 화면 구성 (PC · 휴대폰)

영역내용
왼쪽 사이드바이음 로고, KCOC · 사랑의열매 로고, 메뉴 11개(현재 메뉴 강조 표시). 아래쪽에 사업명, 참여 기관 수, 운영 기간
상단 바“사업명 / 현재 메뉴”, 로그인한 관리자 이름·직책, [로그아웃]
보고서 종류 탭통합 대시보드, 자료 제출 · 검토, 최종 자료실 상단. 사업 설정에 등록한 보고서(예: 중간보고서 · 결과보고서 · 최종 결과보고서)가 마감일과 함께 표시되며, 처음에는 마감이 지나지 않은 첫 보고서가 선택됩니다
회차 탭컨설팅 일정 상단. 사업 설정의 컨설팅 회차(예: 상반기 필수컨설팅 · 하반기 필수컨설팅 · 선택컨설팅). 필수 회차에는 ‘필수’ 표시
토스트 메시지저장·승인·발송 결과가 화면 아래에 약 3초간 표시됩니다

휴대폰 · 태블릿에서 볼 때

  • 화면 폭이 좁으면(약 820px 이하) 왼쪽 사이드바가 상단 가로 메뉴로 바뀝니다. 메뉴를 옆으로 밀어 다른 메뉴를 고릅니다.
  • 나란히 있던 카드는 세로로 쌓이고, 넓은 표는 카드 안에서 옆으로 밀어서 봅니다.
  • 좁은 화면에서는 로고와 사이드바 아래쪽 안내가 숨겨집니다.
검토 의견 작성, 매칭 승인, 사업 설정처럼 입력이 많은 작업은 PC에서 하는 것이 편합니다. 휴대폰은 현황 확인·간단한 승인에 쓰세요.

1.3 세 가지 역할과 볼 수 있는 범위

역할누구메뉴와 할 수 있는 일
관리자파트너십지원부 사무국메뉴 11개 전체. 검토·승인, 컨설팅 배정·확정, 설정, 계정·기관 관리
기관수행기관 담당자내 사업 현황 · 자료 제출 · 연간 사업 일정 · 컨설팅 일정 · 예산변경 / 사업변경 · 공지사항. 보고서 제출, 컨설팅 희망 순위 선택 또는 선택컨설팅 신청서 제출, 회차별 사전 정보 작성, 내부 예산변경 입력·승인 문서 제출, 담당자 정보 수정
전문가외부 컨설턴트자료 제출 · 컨설팅 일정. 회차별 가능 일시 체크와 추가 가능 시간 기입, 본인 담당 확정 일정과 담당 기관의 사전 정보·신청서 열람, 전문가 보고서 제출
데이터 격리: 기관은 자기 기관의 정보만, 전문가는 본인이 담당으로 배정된 기관의 정보만 볼 수 있습니다. 이 제한은 화면이 아니라 데이터베이스 권한으로 강제되므로, 주소를 바꾸거나 다른 방법으로 접근해도 다른 기관 자료는 열리지 않습니다. 관리자만 전체를 봅니다.

기관 계정은 선발연도 + 2년(3년)까지만 쓸 수 있습니다. 기간이 끝나면 로그인 후 “이용 기간이 종료된 계정입니다” 화면만 보입니다. 기관이 삭제된 기관 계정은 “연결된 기관이 없는 계정입니다”가 나옵니다.

3. 메뉴별 사용법

3.1 통합 대시보드

로그인 직후 보이는 현황판입니다. 상단 보고서 종류 탭을 바꾸면 그 보고서 기준으로 숫자가 바뀝니다.

카드내용
상단 집계미제출 / 검토 중 / 수정 요청 / 최종 완료 건수와 승인 대기 문서(예산·사업변경) 수
기관별 제출 현황최대 6개 기관의 진행 상태·최근 제출·버전. 검토하기 →로 해당 기관 검토 화면, 전체 보기 →로 자료 제출 · 검토 이동
승인 대기 문서기관이 올린 예산변경·사업변경 승인 신청 목록. 검토 →로 예산변경 / 사업변경 이동
완료율선택한 보고서의 최종 승인 비율
하반기 필수컨설팅일정을 신청한 기관 수 / 전체 기관 수, 확정 건수. [컨설팅 일정 관리 →]
최근 활동활동 로그 최근 4건. 전체 로그 →
안내 메일 발송 실패 건은 대시보드가 아니라 컨설팅 일정 화면의 해당 기관 행에 ‘발송 실패 · 재시도’로 표시됩니다.

3.2 자료 제출 · 검토

기관이 올린 보고서를 검토·승인합니다. 상단 탭에서 보고서 종류를 고르고, 목록에서 검토하기 →를 누릅니다. 목록 위에서 기관명 검색과 상태 필터(모든 상태 / 미제출 / 제출됨 / 검토 중 / 수정 요청 / 최종 완료)를 쓸 수 있습니다.

상태 흐름

미제출 → 제출됨 → 검토 중 → (수정 요청 → 기관 재제출 → 제출됨 …) → 최종 완료

검토 절차

  1. 기관 상세 화면의 제출 버전 이력에서 버전(v1, v2 …)별 파일과 기관의 변경 사항 메모를 확인합니다. [다운로드 ↓]로 파일을 받습니다(다운로드는 활동 로그에 기록).
  2. 상태가 ‘제출됨’이면 [검토 시작]을 누릅니다. 기관 화면에 ‘검토 중’으로 표시됩니다.
  3. 검토 의견 작성 칸에 의견을 적습니다. 어느 항목을 어떻게 고치고 무엇을 첨부하면 되는지 구체적으로 적어 주세요.
  4. 수정이 필요하면 [수정 요청]. 의견이 ‘수정 필요’로 등록되고 상태가 ‘수정 요청’이 되며, 수정 기한(사업 설정의 기한, 기본 7일)이 자동으로 붙습니다.
  5. 기관이 수정본을 올리면 다시 ‘제출됨’이 됩니다. 2번부터 반복합니다. 기관이 의견에 답변하면 의견 아래에 표시됩니다.
  6. 문제가 없으면 의견(예: “최종 승인합니다”)을 적고 [최종 승인]. 상태가 ‘최종 완료’가 되고, 마지막 버전에 ‘최종본’ 표시가 붙어 최종 자료실에 모이며, 기관에 알림이 갑니다.
[수정 요청]과 [최종 승인] 모두 의견을 입력해야 눌립니다. 등록한 의견은 수정·삭제할 수 없고, 최종 승인을 되돌리는 버튼도 없습니다. 누르기 전에 한 번 더 확인하세요. 잘못 처리했으면 시스템 담당자에게 요청합니다.

3.3 연간 사업 일정

  • 1차년도 / 2차년도 / 3차년도 수행기관 탭과 분류 필터(전체 · 컨설팅 · 모니터링 · 보고서 제출 · 제출 마감 · 기타)로 봅니다. 분기·월별로 정리되고, 이번 달에는 ‘오늘’ 표시가 붙습니다.
  • 오른쪽 위 [일정 편집] → ‘편집 모드 · 관리자 전용’이 됩니다.
    • 추가: 월 · 시기(예: 9월 3주차) · 일정명 · 분류를 입력하고 [추가]. 시기와 일정명은 필수입니다.
    • 수정: 각 일정의 시기·일정명 칸을 고친 뒤 칸 밖을 누르면 저장됩니다. 분류는 고르는 즉시 저장됩니다.
    • 삭제: 각 일정의 [삭제]. 확인 창 없이 바로 지워집니다.
  • 끝나면 [편집 종료]. 변경 내용은 기관 화면에 즉시 반영됩니다.

3.4 컨설팅 일정

상단 회차 탭마다 따로 진행합니다. 회차는 사업 설정에서 정한 방식에 따라 화면이 다릅니다.

방식보통 쓰는 회차흐름
일정 선택 방식상반기 · 하반기 필수컨설팅전문가 가능 일시 조사 → 담당 전문가 배정 → 기관 공개 → 기관이 1·2·3순위 선택 → 사무국 매칭 승인 → Zoom 안내
신청서 방식선택컨설팅기관이 신청서 제출 → 사무국이 신청서 확인·인쇄 → 전문가·일시 배정 → Zoom 안내

A. 필수컨설팅 (일정 선택 방식)

화면은 1단계 · 전문가 가능 일시 카드, 2단계 일시별 현황 카드, 기관별 일정 신청 표, 사전 정보 카드 순서입니다. 1단계 카드 오른쪽 위에 현재 상태가 표시됩니다: ‘전문가 조사 중 · 기관에는 아직 안 보임’ → ‘기관 공개 예정 · ○월 ○일 ○시’ → ‘기관 접수 중’.

단계누가어디서무엇을
①관리자사업 설정 → 컨설팅 회차후보 일시 등록. 날짜만 넣고 시간을 비우면 그날 09:00~18:00이 소요 시간(기본 120분) 단위로 나뉩니다(예: 09:00 · 11:00 · 13:00 · 15:00 네 칸). 전문가에게 조사 참여를 별도로 안내합니다(포털이 자동 메일을 보내지 않음)
②전문가전문가 화면 → 컨설팅 일정가능한 시간대 체크 + 후보 외 가능 시간을 주관식으로 적고 제출
③관리자1단계 카드날짜×시간대 격자에서 칸마다 가능한 전문가 이름 확인. 전문가별 응답 표에서 ‘응답 이전 / 응답 완료’, 선택한 일시, 추가 가능 시간(주관식) 확인. 카드 제목 옆 ‘○/○명 응답’ 참고. 응답이 부족하면 전문가에게 추가 요청
④관리자1단계 카드 → 기관별 담당 전문가기관마다 전문가를 고릅니다(‘미배정’ 가능). 고르는 즉시 저장되고 활동 로그에 남습니다. 기관은 담당 전문가의 가능 일시만 보게 됩니다
⑤관리자1단계 카드 → 기관 공개 시작 일시날짜·시각을 넣고 [저장]. 공개를 취소하려면 [해제] 후 [저장]
⑥기관기관 화면 → 컨설팅 일정공개 시각부터 담당 전문가의 가능 일시만 보이고, 순서대로 최대 3개 체크(1·2·3순위) 후 제출. 같은 전문가를 쓰는 다른 기관이 1순위로 고른 칸이나 이미 확정된 칸은 ‘타 기관 컨설팅 일정 선점’으로 잠깁니다
⑦관리자기관별 일정 신청 표기관 이름 아래 담당 전문가, ‘희망 순위’ 칸에 1순위 22일 11:00 ~ 13:00 … 형식으로 표시됩니다. 상태는 ‘신청 완료’
⑧관리자기관별 일정 신청 표첫 번째 목록에서 확정할 순위(기본 1순위), 두 번째 목록에서 담당 전문가를 고르고 [매칭 승인]. 상태가 ‘확정’이 되고 기관에 알림이 갑니다
⑨전문가·기관각자 화면확정된 일정 표시. 전문가는 본인 담당 건만, 기관은 자기 것만 봅니다
매칭 승인이 막히는 경우
• 그 일시에 확정된 기관 수가 일시별 정원(사업 설정, 기본 2)에 도달 → “정원 ○개 기관이 모두 찼습니다”
• 같은 전문가가 같은 시간에 다른 기관에 이미 확정 → “해당 전문가의 타 기관 컨설팅이 확정되어 있습니다”. 전문가 목록에서도 ‘· 타 기관 컨설팅 확정’으로 표시되어 고를 수 없습니다.
2단계 카드에서 날짜별·시간대별 ‘확정 ○/정원’, ‘체크 ○개 기관’, 확정된 기관·전문가 이름을 한눈에 볼 수 있습니다.

B. 선택컨설팅 (신청서 방식)

기관이 신청서를 제출하면 선택컨설팅 신청서 표에 한 줄씩 나타납니다(‘○개 기관 신청 · ○건 배정’).

열내용
기관기관명, 제출 일시, ‘배정 대기’ 또는 ‘배정 완료’
신청 내용희망 분야와 신청 사유 앞부분. [신청서 보기]로 전체 내용(담당자명, 참석자, 희망 분야, 신청 사유, 세부 질의사항, 희망 컨설턴트)을 창으로 보고, [인쇄]로 로고가 들어간 신청서를 인쇄합니다
희망 전문가기관이 적은 희망 컨설턴트. 비어 있으면 ‘없음 · 사무국 배정’
전문가 · 일시 배정전문가 선택, 날짜, 시각을 넣고 [배정·확정](이미 배정했으면 [변경]). 기관에 알림이 갑니다
Zoom 링크 / 안내 메일배정 후 입력 가능. 아래 C 참고
날짜는 필수이고 시각은 비워도 됩니다. 같은 전문가가 같은 일시에 다른 기관에 확정돼 있으면 배정이 막힙니다. [인쇄]를 눌러도 창이 안 뜨면 브라우저에서 이 사이트의 팝업을 허용해 주세요.

C. Zoom 안내 메일 보내기 (확정·배정 후, 두 방식 공통)

  1. 해당 기관 행의 입력칸에 Zoom 링크(https://로 시작)를 붙여넣고 [저장·발송]을 누릅니다.
  2. “안내 메일 발송 전 확인” 창에 받는 사람(기관 담당자 이메일), 제목, 본문이 실제 값으로 채워져 보입니다. 확인 후 [발송], 고칠 게 있으면 [취소].
  3. 성공하면 행 아래에 ‘발송 일시 → 이메일’이 표시되고 기관에 알림이 갑니다.
  4. 실패하면 “Zoom 링크는 저장했지만 메일 발송에 실패했습니다”가 뜨고 행에 ‘발송 실패 · 재시도’가 남습니다. 재시도를 누르면 같은 확인 창을 거쳐 다시 보냅니다.

받는 사람은 기관이 ‘내 사업 현황 → 담당자 정보’에 직접 등록한 이메일입니다. 메일은 포털의 발신 메일 계정에서 나갑니다(현재 Gmail 계정, 추후 회사 메일로 전환 예정). 메일 문구는 사업 설정 → 컨설팅 확정 안내 메일에서 바꿉니다.

D. 사전 정보 (회차별)

일정 선택 방식 회차 화면 맨 아래 ‘회차명’ 사전 정보 카드에 기관이 그 회차 전에 작성한 내용이 모입니다. 회차마다 따로 저장되므로 상반기에 쓴 내용이 하반기 탭에 보이지 않습니다. 항목: 예산 집행률(%), 세부활동별 진행현황, 현지 여건 및 주요 이슈, 전문가 자문 요청사항. 담당 전문가도 자기 화면에서 같은 내용을 봅니다.

자주 묻는 것

  • 기관 공개 시각을 미리 지정할 수 있나요? 예. 미래 시각으로 저장하면 기관 화면에 “○○○○년 ○월 ○일(○) ○○시부터 컨설팅 일자 선택이 가능합니다”라고 안내되고, 그 시각에 자동으로 열립니다. 공개 일시가 없으면 기관에는 “사무국이 전문가 일정을 조율하고 있습니다”로 보입니다.
  • 담당 전문가를 바꾸면? 기관 화면의 가능 일시가 새 전문가 기준으로 바뀝니다. 이미 제출한 순위는 남아 있으니 기관에 다시 선택하도록 안내하세요.
  • 확정을 바꾸려면? 기관별 표에서 일시·전문가를 다시 고르고 [변경]. 기관에 알림이 갑니다. Zoom 안내 메일은 다시 보내야 합니다.
  • 전문가 계정을 새로 만들면? 계정 관리에서 전문가 계정을 발급하는 즉시 이 화면의 전문가 목록에 나타납니다.

3.5 예산변경 / 사업변경

상단 탭 4개로 구성됩니다.

탭내용
승인 대기 (건수)기관이 올린 예산변경·사업변경 승인 신청 문서. 기관명, 구분, 변경 금액(예산변경), 사유, 제출 일시. [다운로드 ↓]로 문서를 검토하고, ‘승인 메모 (선택)’를 적은 뒤 [승인]. 기관에 알림이 갑니다
승인 완료처리 이력. 승인 일시와 승인자 표시
기관별 변경 현황기관별 당해년도 예산, 내부 변경 건수·누적, 승인 문서 누적, 합산, 비율. 비고에 ‘한도 내’, ‘내부 1천만원 초과’, ‘20% 초과’ 표시
기관 예산 총액기관마다 3개년 사업예산 총액과 당해년도 사업예산 총액(원)을 입력하고 [저장]. 값을 바꾼 행만 저장 버튼이 활성화됩니다

규칙 (기관 화면에서 자동 적용)

  • 기관은 승인이 필요 없는 내부 예산변경을 직접 입력합니다. 변경 금액은 증감과 관계없이 절댓값으로 누적됩니다.
  • 내부 누적이 1천만 원 초과, 목(세목) 간 전용, 신규 세목·세세목 추가, 국내/현지 예산계획 변경 중 하나라도 해당하면 입력이 막히고 승인 문서 제출로 안내됩니다.
  • 내부 + 승인 문서 누적이 당해년도 사업예산의 20%를 넘는 변경은 등록·제출할 수 없습니다.
20% 한도는 ‘기관 예산 총액’ 탭의 당해년도 사업예산 총액을 기준으로 계산합니다. 연초에 반드시 기관별 예산 총액을 등록하세요. 미등록 기관은 현황 표에 ‘미등록’으로 보이고 비율이 계산되지 않습니다.

3.6 최종 자료실

최종 승인된 보고서의 최종본 파일만 모아 보는 곳입니다. 보고서 종류 탭을 바꿔 가며 기관별 파일을 [다운로드 ↓]로 받습니다. 상단에 승인 기관 수와 총 용량이 표시되고, 다운로드 기록은 활동 로그에 남습니다.

3.7 참여 기관

  • 필터: 전체 기관 / 1·2·3차년도 수행기관(각각 기관 수 표시).
  • 차년도별 카드에 기관명, 선발연도와 이용 기간, 현재 선택된 보고서의 진행 상태가 보입니다. 제출 자료 →를 누르면 그 기관의 검토 화면으로 이동합니다.
  • 맨 아래 이용 종료 기관(3년 경과 · 로그인 차단)이 따로 표시됩니다.

기관 추가·삭제는 이 화면이 아니라 계정 관리에서 합니다(3.10).

3.8 공지사항

기관·전문가가 보는 것과 같은 공지 목록입니다. 작성·수정·삭제는 사업 설정 → 공지사항에서 합니다(3.11).

3.9 활동 로그

누가 언제 무엇을 했는지 최신순으로 기록됩니다. 위쪽 검색칸에 기관명·처리 내용을 넣어 찾습니다. 삭제·수정할 수 없으며, 문의 대응이나 인수인계 때 근거로 씁니다.

3.10 계정 관리

계정 발급

  1. 계정 발급 카드에서 역할(기관 / 전문가 / 관리자)을 고릅니다.
  2. 기관이면 기관 선택(이용 기간 중인 기관만 표시), 전문가·관리자면 이름과 직책을 입력합니다(이름 필수).
  3. 로그인 이메일과 임시 비밀번호(8자 이상)를 입력하고 [발급].
  4. 초대 메일은 발송되지 않습니다. 이메일과 임시 비밀번호를 본인에게 직접 전달하고, 첫 로그인 후 ‘비밀번호 재설정’으로 바꾸도록 안내합니다.
전문가는 섭외될 때마다 추가하면 됩니다. 한 기관에 계정을 여러 개 만들 수도 있습니다. 기관 계정의 담당자 이름·이메일은 기관이 ‘담당자 정보’에서 직접 관리합니다.

참여 기관 추가

  1. 참여 기관 추가 카드에 기관명을 입력합니다.
  2. 선발연도를 고릅니다(사업연도 기준 “○○○○년 선발 (1차년도)”, 2차년도, 3차년도 중 선택). 차년도와 이용 기간(선발연도 + 2년)이 자동 계산됩니다.
  3. [추가]. 이어서 그 기관의 계정을 발급하고, 예산변경 / 사업변경 → 기관 예산 총액에 예산을 등록합니다.

기관 삭제

  1. 참여 기관 추가 카드 아래 기관 목록에서 해당 기관의 [삭제]를 누릅니다.
  2. “‘기관명’ 기관 삭제” 창에 경고가 표시됩니다: 제출 자료 · 예산변경 · 컨설팅 일정 등 이 기관의 모든 데이터가 영구 삭제되며, 연결된 기관 계정도 함께 삭제됩니다(개수 표시).
  3. 로그인한 관리자 본인의 비밀번호를 입력하고 [삭제]. 비밀번호가 틀리면 “비밀번호가 일치하지 않습니다.”로 중단됩니다.
  4. 삭제 결과는 활동 로그에 ‘기관 삭제’로 기록됩니다.
기관 삭제는 되돌릴 수 없습니다. 이용 기간이 끝난 기관은 삭제하지 않아도 자동으로 로그인이 막히므로, 잘못 등록한 기관을 지울 때만 쓰세요. 실수로 지웠다면 즉시 시스템 담당자에게 알리세요(5장 백업 참고).

계정 목록 — 수정 · 삭제

  • 목록에 구분(관리자 / 기관 / 전문가), 이름 또는 기관명, 이메일이 보입니다. 기관이 삭제된 기관 계정은 ‘삭제된 기관’으로 표시됩니다.
  • [수정]: 관리자·전문가 계정의 이름과 부서·직책을 고치고 [저장](또는 [취소]). 상단 표시는 다시 로그인하면 바뀝니다. 기관 계정에는 수정 버튼이 없습니다.
  • [삭제]: “○○ 계정을 삭제할까요? 로그인이 즉시 차단됩니다.” 확인 창에서 확인을 누르면 삭제됩니다. 본인 계정에는 삭제 버튼이 없습니다.
  • 이메일은 바꿀 수 없습니다. 새 이메일로 계정을 발급하고 기존 계정을 삭제하세요.
관리자 계정은 최소 2명 이상 유지하세요. 담당자 부재 시 다른 관리자가 검토·승인·설정을 이어갈 수 있어야 합니다.

3.11 사업 설정

연도별로 바뀌는 값을 코드 수정 없이 관리합니다. 고친 뒤 오른쪽 위 [저장]을 눌러야 반영되며, 저장하면 기관·전문가 화면에 즉시 반영되고 활동 로그에 ‘사업 설정 변경’이 남습니다. 필수값이 비어 있으면 “확인 필요: …”로 알려 주고 저장되지 않습니다.

5. 지켜야 할 것

  • 비밀번호는 개인별로 관리하고 공유하지 않습니다. 관리자 계정은 담당자마다 따로 발급합니다.
  • 관리자 계정은 최소 2명 이상 유지합니다.
  • 검토 의견, 최종 승인, 계정 삭제, 기관 삭제는 되돌릴 수 없으니 누르기 전에 한 번 더 확인합니다.
  • 기관 삭제 창에 본인 비밀번호를 넣는 것은 “정말 삭제하겠다”는 확인입니다. 다른 사람이 대신 입력하지 않게 합니다.
  • 기관·전문가의 개인정보(연락처, 이메일)와 제출 자료는 포털 안에서만 확인하고 외부로 내보내지 않습니다. 임시 비밀번호는 본인에게만 전달합니다.
  • 사업 설정 변경은 팀 내에서 합의한 뒤 한 사람이 합니다. 변경 내용은 활동 로그에 남습니다.
  • 공용 PC에서는 작업이 끝나면 반드시 [로그아웃]합니다.
